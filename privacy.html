איזה מידע נשמר

האפליקציה שומרת את התזכורות שהמשתמש יצר (כותרת, הערה, תאריך, שעה והגדרות חזרה) בזיכרון המכשיר בלבד.

חיבור ל-Google Drive

אם המשתמש בוחר להתחבר לחשבון Google, האפליקציה מבקשת הרשאה אחת בלבד: drive.file. הרשאה זו מאפשרת לאפליקציה ליצור ולקרוא רק קובץ אחד שהיא עצמה יצרה, בשם hebrew-calendar-sync.json, ב-Drive של המשתמש. הקובץ מכיל את התזכורות לצורך גיבוי ושחזור. האפליקציה אינה יכולה לקרוא קבצים אחרים ב-Drive.

שיתוף מידע

המידע אינו נשלח למפתח האפליקציה ואינו נמכר או משותף עם צד שלישי. אין באפליקציה פרסומות, ניתוח שימוש או מעקב.

מחיקת מידע

אפשר למחוק את התזכורות מתוך האפליקציה, למחוק את הקובץ מ-Google Drive, ולבטל את ההרשאה בכתובת myaccount.google.com/permissions.

Privacy Policy - Hebrew Calendar Reminders

Last updated: November 2026

Data stored. Reminders created by the user (title, note, date, time and repeat settings) are stored on the user's device.

Google Drive. If the user connects a Google account, the app requests only the drive.file scope. This lets the app create and read a single file that it created itself, hebrew-calendar-sync.json, in the user's Google Drive, containing the reminders for backup and restore. The app cannot read any other files in Drive.

Sharing. Data is not sent to the developer and is not sold or shared with third parties. The app has no ads, analytics or tracking.

Deletion. The user can delete reminders in the app, delete the file from Google Drive, and revoke access at myaccount.google.com/permissions.
