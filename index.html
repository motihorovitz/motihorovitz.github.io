לוח עברי - תזכורות

לוח עברי הוא אפליקציית אנדרואיד אישית ללוח שנה עברי ולועזי, עם תזכורות שחוזרות לפי התאריך העברי או הלועזי. היא נבנתה לשימוש אישי של יוצרה, ואינה מופצת בחנות.

האפליקציה שומרת את התזכורות במכשיר, ואם המשתמש מחבר אותה לחשבון Google, היא שומרת גיבוי של התזכורות בקובץ אחד ב-Google Drive של המשתמש עצמו, כדי שאפשר יהיה לשחזר אותן.

Hebrew Calendar Reminders

Hebrew Calendar is a personal Android app for a Hebrew and Gregorian calendar with repeating reminders. It stores reminders on the device and, if the user connects a Google account, saves a backup of the reminders as a single file in the user's own Google Drive.
